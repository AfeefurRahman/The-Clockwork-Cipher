# The Clockwork Cipher

**Category:** Cryptography  
**Difficulty:** Easy  
**Points:** 75  
**Expected solve time:** 2–4 minutes

## Challenge description (paste into your CTF platform)

CyberCorp intercepted a scrambled message from an old finance terminal. The operator left behind a note about a clock that runs seven minutes fast. Recover the original message and submit the flag.

**Flag format:** `CTF{...}`

## Publish with GitHub Pages

Upload `index.html`, `style.css`, and `app.js` to your repository root. In Settings → Pages, configure deployment from the branch containing these files. Open the published site. No backend is needed.
